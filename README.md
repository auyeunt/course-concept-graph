# Course concept graph kit

Turn a course's readings into a concept map, a list of teaching-order problems
in the readings, and sources for a Socratic NotebookLM tutor. Built for the
California Community Colleges, where faculty have Google Colab, Gemini and
NotebookLM through their college accounts, but nothing here is specific to one
college, one subject or one AI model.

## For faculty: the Colab notebook

**[Open the notebook in Google Colab](https://colab.research.google.com/github/auyeunt/course-concept-graph/blob/main/colab/course_concept_graph.ipynb)** and follow the steps
(sign in with your college Google account).
No programming is needed. Read `guide/faculty-guide.md` first: it explains what
each step does, what to check, and what the AI does well and badly.

## How it is put together

| folder | what is in it |
|---|---|
| `prompts/` | every instruction a model reads, as plain text: extract, review, grade, rubric |
| `scripts/` | Python 3 (standard library only; Graphviz for diagrams) that prepares packets for a model and checks everything it says |
| `colab/` | the notebook, generated by `build_notebook.py` |
| `guide/` | the faculty guide |
| `sources/` | a reading added to every tutor notebook: "AI literacy for higher ed students", on why the tutor does not hand over answers |
| `SKILL.md` | the full procedure, written for Claude Code (also the most complete reference for people) |

The model only ever sees a **packet**: one Markdown file holding the
instructions and one reading's numbered text. It answers with a table in which
every claim carries a verbatim quote. The scripts reject any claim whose quote
is not in the reading, any connection that would make a cycle or point to a
later reading, and anything malformed. So any capable model can do the reading,
in a chat window or through an API, and the result is checked the same way.

The pipeline, as command lines (the notebook runs the same thing):

    S=scripts
    python3 $S/extract.py prepare --dir COURSE      # packet for the next reading
    python3 $S/extract.py apply mNN --dir COURSE --write
    python3 $S/edge_audit.py prepare --dir COURSE   # second reading, then verify
    python3 $S/edge_audit.py verify --dir COURSE
    python3 $S/edge_audit.py grade-prepare --dir COURSE
    python3 $S/edge_audit.py grade-apply --dir COURSE --write
    python3 $S/edge_audit.py prune --dir COURSE --write
    python3 $S/edge_audit.py forward --dir COURSE
    python3 $S/check.py --dir COURSE
    python3 $S/render.py --dir COURSE
    python3 $S/notebooklm.py --dir COURSE

## How well it works

Tested in November 2026 on a computer architecture course (CISP 310) against a
reference graph built with Claude: the free Gemini models invented no quotes
in any test; the Gemini app's Thinking model found about 80% of the
connections the reference found and recovered the same teaching-order
problems; Colab's built-in Flash model found about half to three quarters
as much. Details are in the faculty guide.
